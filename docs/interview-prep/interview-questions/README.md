- **Foundation** — you must not miss these.
- **Strong SWE** — the level that decides most mid/senior backend loops.
- **Advanced** — staff-level probing and hostile follow-ups.

Answers are deliberately terse. Try to answer before reading, and follow
the link when you can't.
